# Driver Analytics PWA

## Purpose
PWA to help enable Service Workers in British Columbia to track datapoints such as mileage, engaged time, and recieved payments so that they may ensure their online platform is following Employement Standards.

## Project Plan
**In Scope**:
- Offline-only
- Data kept on user device
- Easy to use even during busy periods
- Data export into usable formats (e.g. csv)

**Not In Scope**:
- Online functionality
- Server hosting for data back up
- In-application insights and data analysis
- Legal advice regarding Employement Standards
